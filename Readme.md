## 📖 About

This repository documents my journey of learning **Data Structures and Algorithms in C++**.

Unlike a typical solutions repository, each concept is implemented and explored through multiple approaches whenever possible, ranging from brute force solutions to optimized implementations.

The goal is to understand not only *how* a solution works, but also *why* certain optimizations improve performance.

---

## 🎯 Goals

* Build strong problem-solving skills
* Learn DSA from fundamentals to advanced topics
* Compare brute force and optimized approaches
* Maintain consistency through regular practice
* Prepare for coding interviews and competitive programming

---

## 📂 Repository Structure

The repository is structured into topic-based directories to keep concepts clearly separated and easy to navigate. Each file represents a specific problem, algorithm, or concept.

```text
📦 DSA
 ┣ 📂 1. The Basics
 ┣ 📂 2. Sorting Techniques
 ┣ 📂 3. Array Problems
 ┣ 📂 4. Binary Search
 ┣ 📂 scripts
 ┃ ┗ 📜 update_progress.py (Automates progress tracking)
 ┗ 📜 Readme.md
```

Most implementations include:

* Brute Force Approach
* Better Approach
* Optimal Approach
* Explanatory Comments
* Time & Space Complexity Insights

## 🤖 Automated CI/CD Workflow

This repository uses **GitHub Actions** to automatically maintain its health and quality:
* **Syntax Verification:** Every push automatically compiles the changed `.cpp` files using `g++` to catch syntax errors early.
* **Auto-Updating Progress:** A custom Python script counts the solved problems across all topic folders and dynamically updates the Progress table below.
